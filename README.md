# Projects

Project pages and reports by Rogelio Ruzcko Tobias, published at https://ruzcko.com/projects/.

Each project is a folder of static files, served at `ruzcko.com/projects/<folder>/`. Pushing to `main` deploys through GitHub Actions (Settings → Pages → Source: GitHub Actions). Name folders after the work, for example `ind-rainfall-downscaling`, and add each project to `index.html`.

Projects are built in their own working folders and copied here when finished. Commit finished versions only: every commit of changed images stays in the history.

- `ind-rainfall-downscaling`: built from `~/Projects/Presentations/G-26IND-A/page` with `python3 publish.py`.
